# Icon meanings — the Cybele Design System set

**What each icon in the library actually depicts, so the right one can be chosen by meaning rather
than by guessing at its name.** Maintained by the designer from the components themselves; this file
is a copy of that list and is replaced wholesale when she updates it.

**How to use it.** Read the row whose meaning matches what the pill or card is about, and use that
name. The names are the component names in the **Cybele Design System**, page *Icons*, group
*Group 1* — the same names `search_design_system` returns. Search the design system only when
nothing here fits; this file is the faster and more reliable route.

- **Never choose `absolute-touch-NO-SE-USA`.** The component carries that warning in its own name.
- A name here is what to search for. How to fetch, size and colour the icon is in
  `SECTION_RULES.md` -> *Icons (section illustrations)*.
- Two names are worth reading twice before using: **`x`** is the social network's logo, not a close
  button (that is `cancel`), and **`loginradius`** is a CIAM vendor, not the RADIUS network protocol.
