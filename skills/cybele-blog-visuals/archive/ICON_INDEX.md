# Cybfont Icon Index — icons used so far

> **A record, not a rule.** This is the inventory of Cybfont icons used in past Cybele blog
> illustrations: the icon's name, what it looks like, and the article section it appeared in. It is
> here so an icon can be found by concept ("something that says alarm" -> `alert-sign`) without
> opening Figma.
>
> It does not restrict anything. The Cybfont library has 131 icons; these are simply the ones used
> up to now. Pick by what the illustration has to communicate.
>
> The rules for **how** to fetch, embed and recolour a Cybfont icon live in
> [`SECTION_RULES.md`](SECTION_RULES.md) -> *Cybfont Iconography*. Moved out of that file on
> 2026-09-04, so the specification holds only rules.
