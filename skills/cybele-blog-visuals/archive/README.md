# archive/

**Nothing in this folder is a rule, and no run may open it.** Everything here was read on every run
and governed nothing — the cost was real and the benefit was zero. It is kept because it is history
worth recovering, not because it is worth consulting.

| What | Why it is here |
|---|---|
| `PROGRESS.md` | Project journal of the generative era |
| `HANDOFF.md` | How the generative cover system was derived |
| `RECONCILIATION.md` | How two parallel sessions were merged |
| `COVER_SYSTEM_RETIRED.md` | The archetypes, colour families and gradient recipes that used to sit at the end of the cover spec |
| `ICON_INDEX.md` | The twenty-four Cybfont icons past articles happened to use, from when the set was thought to hold 131. Superseded by `../ICON_MEANINGS.md`, which carries all 532 with what each one depicts |
| `covers-2026-03/` | The twenty-one covers that system produced. Cybele's covers no longer look anything like these; never open them to calibrate |

If you are looking for a rule: covers are `../BLOG_COVER_RULES.md`, section illustrations are
`../SECTION_RULES.md`, brand tokens are `../BRAND_DESIGN_RULES.md`, and why a rule changed is
`../HISTORY.md`.
